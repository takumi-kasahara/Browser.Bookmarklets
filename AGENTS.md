# Project Guidelines

This project is a collection of browser bookmarklets that extend web browsing functionality with utility scripts. The project uses modern JavaScript (ES modules) with esbuild for bundling and minification.

## Overview

1. `src/` directory: Contains all source code
   - `src/modules/` - Reusable utility functions used by bookmarklets
   - `src/scripts/` - Individual bookmarklet scripts organized by category
2. `dist/` directory: Generated during build process
   - Contains minified bookmarklets ready to use
   - Generated by `npm run build:minify`
3. `pages/` directory: Web-based distribution
   - Contains the installation page with bookmarklet links
   - Generated by `npm run build:page`

## Workflow

### Available Commands

- `npm run build:minify` - Bundles and minifies all bookmarklets using esbuild
- `npm run build:page` - Generates the installation HTML page
- `npm run build` - Runs both minify and page generation sequentially

### Key Tooling

- esbuild: Fast JavaScript bundler and minifier
- ESLint: Code linting (configured via `eslint.config.mjs`)
- Node.js ES modules: Uses `"type": "module"` in package.json

## Module Organization

### Core Modules (`src/modules/`)

- DocumentExtensions.js
  - DOM manipulation utilities (element creation, waiting, etc.)
- HtmlExtensions.js
  - HTML-specific helpers
- JsonExtensions.js
  - JSON parsing and manipulation
- NavigatorExtensions.js
  - Navigator API helpers (clipboard, etc.)
- WindowExtensions.js
  - Window utility functions

### Script Categories (`src/scripts/`)

- Copy*.js
  - Copy page information to clipboard
- Search*.js
  - Search url or page content on various platforms
- Translate*.js
  - Translate page content
- Share*.js
  - Share page on social media platforms
- console/
  - Firefox-specific scripts

## File Naming Conventions

- Bookmarklet script filenames should be descriptive and use Title Case (e.g., `Copy Host.js`, `Search on Twitter for url.js`)
- Module filenames should use descriptive names with extension pattern `*Extensions.js`

## When Adding New Bookmarklets

1. Create the script in the appropriate `src/scripts/` subdirectory
2. Import utility modules from `src/modules/` as needed
3. Follow naming conventions - Function names start with verbs, variables with nouns
4. Use JSDoc comments for parameters and return types
5. Export pure functions where possible
6. Run `npm run build` to verify minification succeeds
7. Test the minified version in your target browser (Firefox)
